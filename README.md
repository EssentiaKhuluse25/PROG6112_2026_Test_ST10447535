# Console Sales Application

A Java console application that prints the total console device sales for an electronics store.

## Features
- User selects a console device type
- User enters store name
- User enters total sales amount
- Prints a formatted sales report

## Classes
- `IConsoles` – Interface defining the contract
- `Console` – Abstract class implementing IConsoles
- `ConsoleSales` – Subclass that prints the report
- `RunApplication` – Main class that runs the application

## How to Run
1. Open in NetBeans or any Java IDE
2. Run `RunApplication.java`
3. Follow the on-screen prompts
